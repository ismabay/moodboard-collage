# Moodboard Collage

An Eagle plugin that turns selected images into a single moodboard image, right from your library.

Arrange, annotate, and export as one image, saved into boards you can reopen anytime.

## Features

- Grid (uniform square cells), Flow (gapless masonry), or Free (drag, resize, overlap) layouts — switch anytime without losing your work
- Text cards with per-selection bold, color, size, alignment, borders, and backgrounds
- Draw straight lines, freehand marks, or click-to-place zigzags (snapped to 45° angles) with adjustable thickness, color, dashing, and start/end arrowheads
- Five preset colors plus your five most recently used custom colors, shared across every drawing tool
- Drag images in from Finder/browser (single or multiple at once, auto-arranged in a 3-row block), or add more from your Eagle library with a searchable picker
- Automatic save with up to 19 undo steps (button or Cmd/Ctrl+Z), and a live cover preview for every board
- Export as JPG or PNG back into your library

## Install

Load as an unpacked Eagle plugin:

1. Clone or download this repo
2. In Eagle: **Plugin Center → Developer → Import**
3. Select this folder

No external accounts, API keys, or network access required — everything runs locally within Eagle.

## Development

Plain HTML/CSS/JS, no build step. See `manifest.json` for the plugin entry point.
